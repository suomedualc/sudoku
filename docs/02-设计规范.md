# 设计规范（手写纸 · 简约油墨）

> 版本：v2.0（2026-10-06）· 由「miuix 组件外观」全面改版为「手写纸 · 简约油墨」自绘视觉语言
> 目标：黑白手写纸气质——只用纸与墨，靠**线重 / 线型 / 墨的浓淡 / 留白**表达层次；单机游戏，界面不含对弈、联网或社交。
> 关联：`docs/01` 架构设计 · `docs/03` 开发流程 · `docs/04` AI 协作 · `docs/05` 发展规划 · `.codebuddy/rules/sudoku-dev.md` 开发纪律

## 1. 三条铁律

1. **只有纸与墨**：纸 = `Ink.Paper(#F7F5F0)`，墨 = `Ink.Black(#1B1A17)` / `Ink.Grey` / `Ink.Light`。
   **禁止任何色相**——包括"用红色标错"。层次一律靠墨的浓淡（alpha）与线条本身。
2. **手绘而非几何**：所有边框、网格、勾选、排线都用 `inkLine / inkRoundRect / inkHatch` 绘制
   （折线微弯 + 叠一遍淡墨，模拟笔触不匀）。抖动的种子是**纯函数**（由位置/文本哈希决定），
   因此重绘与重组时线条完全静止，不会"抖"。
3. **留白优先**：间距节奏比 Material 更疏（Md 16 / Lg 24 / Xl 32 / Xxl 48 dp）；
   宁可加大留白，也不加装饰与分隔块。

## 2. 令牌（只有两个出口）

### 2.1 `ui/theme/Ink.kt` —— 颜色 / 字体 / 绘制原语

| 类别 | 令牌 | 值 / 说明 |
|---|---|---|
| 纸 | `Ink.Paper` / `Ink.PaperShade` | `#F7F5F0` / `#EDE9DF`（极淡暖白，避免彩色观感） |
| 墨 | `Ink.Black` / `Ink.Grey` / `Ink.Light` | `#1B1A17` 主墨；`#4B4843` 次级；`#8B867C` 最淡（提示文字） |
| 墨的浓淡 | `Ink.Alpha.Line / LineSoft / Hair / Wash / WashStrong / Disabled` | `0.88 / 0.42 / 0.16 / 0.07 / 0.14 / 0.26` |
| 线宽（px） | `Ink.StrokeWidth.Hair / Thin / Bold / Frame` | `0.8 / 1.3 / 2.0 / 2.4` |
| 字体 | `Ink.InkFont` + `Ink.style(size, color, weight, letterSpacing)` | 系统手写体，取不到回退衬线体（见 §2.3） |
| 绘制原语 | `inkLine` / `inkRoundRect` / `inkHatch` | 手绘直线（含虚线模式）、手绘圆角矩形、斜排线 |

### 2.2 `ui/theme/DesignTokens.kt` —— 尺寸

| 类别 | 令牌 | 值 |
|---|---|---|
| 间距 | `Spacing.Xs/Sm/Md/Lg/Xl/Xxl` | 4 / 8 / 16 / 24 / 32 / 48 dp |
| 圆角 | `Radius.Cell / Button / Panel` | 6 / 12 / 16 dp（宁小勿大，过大就不像手画的了） |
| 尺寸 | `Sizes.WideBreakpoint` / `ControlPanel` / `MenuMaxWidth` / `MenuItemHeight` / `CompactItemHeight` / `SketchSize` / `SnackbarReserve` | 720 / 360 / 400 / 60 / 42 / 168 / 64 dp |
| 线宽（dp） | `Stroke.Hair / Thin / Bold / Frame / Grid / GridBold / Selection` | 0.9 / 1.2 / 1.8 / 2.2 / 1.0 / 2.0 / 2.4 dp |

> 分工：**颜色与字体只在 `Ink`，尺寸只在 `DesignTokens`**。组件里不允许出现裸色值或魔法尺寸。

### 2.3 字体来源与授权

- 字体**不随包分发**，只引用本机已安装的系统字体（避免仓库体积与字体再分发授权问题）。
- 桌面（`jvmMain/ui/theme/InkFonts.jvm.kt`）按优先级探测：
  方正硬笔楷书 `FZYTK.TTF` → 霞鹜文楷 `LXGWWenKaiScreen.ttf`（OFL）→ 楷体 `simkai.ttf` → 华文楷体 `STKAITI.TTF`
  → macOS `Kaiti.ttc` → Linux `NotoSerifCJK` / `arphic ukai`。
- 全部失败时回退 `FontFamily.Serif`，**功能不受影响**。
- 后续平台（Android / iOS / Web）若要统一字形，改为打包字体资源（`composeResources/font`），
  届时需重新引入 `compose.components.resources` 依赖——见 `docs/05` §2 阶段 C 的取舍说明。

## 3. 组件规范（自绘墨线组件）

设计意图：**miuix 不再提供视觉组件外观**，只保留骨架与提示通道（见 §3.2）；所有可见控件由 `ui/components/InkWidgets.kt` 自绘。

| 组件 | 职责 | 关键约束 |
|---|---|---|
| `InkSurface`（私有） | 所有可点控件的交互底子 | 统一五态反馈，见下表 |
| `InkButton` | 主 / 次操作按钮（菜单项、控制条） | `emphasized` = 重墨框 + 大字；`compact` = 42dp 高 |
| `InkKey` | 数字键 / 小方块墨键 | `emphasis` 重墨 = 可填；`soft` 淡墨 = 不可填；禁用不禁用功能（见 §6） |
| `InkToggleRow` | 玩法开关 | 整行 `toggleable(role = Role.Switch)`；勾选是手绘"✓"，不依赖颜色 |
| `InkPanel` | 分组容器（替代 Card） | 白纸面 + 淡墨手绘边框 |
| `InkOverlay` | 难度选择 / 退出确认 | 墨色遮罩（16% 黑）+ 居中面板（最大宽 440dp） |
| `InkTitleFrame` | 首页标题 | 双层手绘矩形 + 两侧墨点与短竖线装饰 |
| `InkDivider` | 面板内分隔 | 一条淡墨手绘线（替代分割块） |
| `InkGridSketch` | 首页底部装饰 | 9×9 手绘草图 + 几枚"随手点下的墨迹" |
| `BoardCanvas` | 棋盘 | 见 §6 |

**五态反馈（全站统一，动画时长 90ms）**

| 状态 | 视觉 |
|---|---|
| 常态 | 手绘墨框（中墨 / 重墨 / 淡墨由 `emphasis`、`soft` 决定） |
| 悬停（桌面） | 加一层极淡墨洗（`Alpha.Wash`） |
| 按压 | 墨洗加深 + 整体下移 1dp（"按下去"的手感） |
| 焦点（键盘 Tab） | 内侧再叠一圈细描框 |
| 禁用 | **虚线框** + 淡墨字（不依赖颜色传达"不可用"） |

### 3.1 首页（`MenuScreen`）

结构对齐参考图：**标题墨框 → 竖排主菜单 → 底部棋盘草图**，但只用墨线与留白表达。

- 标题：「数独」+ 副标题「SUDOKU · 手写纸」，居中于双层墨框内，两侧各一墨点 + 短竖线。
- 菜单**仅三个入口**（硬性要求）：
  1. `开始游戏` → 弹出墨框难度面板（简单 40 / 普通 46 / 困难 52 / 大师 56 空），选完直接开局；
  2. `继续游戏` → 进入未完成对局；**无存档时画虚线框并附一行淡墨说明**「暂无未完成的对局」；
  3. `退出游戏` → 二次确认（「退出游戏？」+ 取消 / 退出），并提示"未完成的对局会自动保存"。
- 底部：`InkGridSketch` + 一行淡墨小字「单机 · 无需联网」。
- 间距：标题上下各 `Xxl`；菜单项之间 `Md`；整体左右 `Lg`，内容最大宽 400dp 居中。

### 3.2 miuix 的职责边界（改版后的取舍）

| miuix 组件 | 职责 | 原因 |
|---|---|---|
| `MiuixTheme(colors = lightColorScheme())` | 主题上下文 | 固定浅色纸面（不跟随系统深色，见 §9） |
| `Scaffold` | 页面骨架 + 安全区 `PaddingValues` | 跨端系统栏/刘海适配由它负责（`App.kt` 完整应用 paddingValues） |
| `SnackbarHost` / `SnackbarHostState.showSnackbar` | 一次性提示通道 | 无障碍与生命期管理成熟；深色提示条在纸面上读作"墨块"，与风格自洽 |

> miuix 的 `Button / Card / Switch / SmallTopAppBar / SmallTitle / TextButton` 已**不再使用**：
> 它们的外观（填充色块、Material 圆角、开关轨道）与手写纸气质冲突。
> 这一改版意味着"miuix 版"的含义从"用 miuix 的组件外观"变为"用 miuix 的骨架与主题能力 + 自绘墨线视觉"。

## 4. 对局页布局（`GameScreen`）

- **宽屏**（宽 ≥ 720dp 且宽 > 高）：左侧棋盘 + 右侧控制栏（360dp，独立滚动）。
  棋盘取 `min(可用宽, 可用高 − SnackbarReserve)` 的正方形并**顶部对齐**——为底部提示条预留空间，避免提示盖住棋盘最后一行。
- **窄屏**：纵向排布并整体可滚动（状态行 → 棋盘 → 键盘面板 → 开关面板），棋盘占满宽度。
- 状态行：难度 · 计时（暂停时显示「已暂停」）· 提示次数（用过才显示）× 进度，下方一条淡墨分隔线。
- 暂停：用**白纸全遮棋盘**（不能继续读题）+ 居中「已暂停」与「继续」按钮。
- 数字键盘：每个键右上角用淡墨小字标注"该数字还剩几个"；数字用完时该键转为**淡墨框**（不靠颜色）。
- 操作按钮：撤销 / 重做在栈为空时显示**虚线框**（禁用态）；提示为主操作（重墨框）。

## 5. 棋盘墨线表达（完全不用颜色）

| 信息 | 表达方式 |
|---|---|
| 题目给定数字 | **实墨**（`Ink.Black`） |
| 玩家填入数字 | 淡墨（`Ink.Grey`） |
| 冲突格 | **斜向排线**（`inkHatch`）+ 冲突数字外套一个**手绘圈**，并由 Snackbar 文案说明 |
| 选中格 | 双层手绘框（外粗内细）；**笔记模式下改为虚线框**（用线型区分模式） |
| 同值格 | 一层淡墨洗（`Alpha.Wash`） |
| 同行 / 同列 / 同宫 | 极淡墨洗（`Alpha.Hair × 0.55`） |
| 笔记（候选数） | 3×3 排布的小号淡墨数字 |
| 网格 | 细线 `Grid` + 每 3 格加粗 `GridBold`；整盘外套手绘粗框 |
| 底层 | 棋盘铺纯白（与页面暖白纸形成极淡层次） |

数字字号用 `toSp()` 由格子像素换算（`DrawScope` 本身是 `Density`），因此在任何 DPR / 字体缩放下都与格子等比。

## 6. 交互与键盘

| 操作 | 行为 |
|---|---|
| 首页 | 三个入口 + 难度遮罩 + 退出确认（见 §3.1） |
| 选格 | 点棋盘格 → `Select(pos)` |
| 填数 | 点数字键 / 键盘 1–9 → `Digit(value)`；再次点同数字清除 |
| 擦除 | `Digit(0)`（键位「擦除」/ `0` / `Delete` / `Backspace`） |
| 笔记 | 笔记模式下的数字键切换候选位；落子自动清理同行列宫候选 |
| 提示 | `Hint` 填入正确数字，状态行累计「提示 ×N」 |
| 重置 | 清空玩家填入与提示计数并重新计时（可撤销） |
| 撤销 / 重做 | 恢复 / 重放快照（上限 300 步） |
| 暂停 | 停表 + 白纸遮题；`Esc` / 空格 继续 |
| 看答案 | `Reveal`：reducer 已实现并有单测，**UI 未接入**（改版后未放入任何菜单） |

桌面键盘映射（`GameScreen.handleKeyEvent`）：`1–9` 填数、`0`/`Delete`/`Backspace` 擦除、
方向键选格（**自动跳过给定格**）、`N` 笔记、`H` 提示、`P`/空格 暂停、`Esc` 继续、
`Ctrl+Z` 撤销、`Ctrl+Y`（或 `Ctrl+Shift+Z`）重做。

## 7. 无障碍

- 对比度：墨 `#1B1A17` 与纸 `#F7F5F0` 对比度约 15:1，远超 WCAG AAA。
- **不依赖颜色**：冲突用排线 + 手绘圈 + 文案；禁用用虚线框；可填性用线重；模式用线型。
- 棋盘整体带语义描述（难度 / 已填进度 / 是否暂停 / 是否笔记模式 / 当前选中行列）。
- 所有可点控件统一带 `Role`、焦点态与键盘可达性（Tab 序由 Compose 自动管理）。
- **待补**：格子级语义节点（每格可聚焦 + 行列值朗读）；首页三个入口的键盘上下选择快捷键。

## 8. 窗口与自适应

- 桌面窗口默认 1180×900、最小 940×720（`jvmMain/main.kt`：`rememberWindowState` + `window.minimumSize`）。
- 断点：宽 ≥ 720dp 且宽 > 高 → 双栏；否则纵向滚动。
- 验收窗口档位（每次 UI 改动都要过）：1180×900（桌面默认）、800×600（小窗）、500×1000（手机竖屏比例）、
  平板横屏（1024×768）。
- 高 DPI：尺寸一律 dp / `toSp()`；线宽用 dp 换算，禁止裸像素。

## 9. 主题与配色策略

- **固定浅色纸面**：`MiuixTheme(colors = lightColorScheme())`，不跟随系统深色——
  手写纸风格本身以"纸"为前提，强行反色会失去气质。
- 深色需求走**独立主题设计**（"夜墨"：深底 + 浅墨），列入 `docs/05` §4 Tier 2，届时按主题切换而非自动跟随。
- Monet 动态取色与彩色语义色**不适用于本风格**，不启用。
