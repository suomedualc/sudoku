# 设计评审：一致性审查与国际奖项对标

> 版本：v1.0（2026-10-06）
> 评审对象：`ui/` 全部视觉实现（设计令牌、控件库、两页界面、图标）
> 评审方式：**先量后判**——每条结论都附可复核的数字或文件行号，不做印象式评价
> 对标标尺：CA 国际设计奖（Communication Arts）· 德国设计奖 · IDEA · 红点奖

---

## 1. 评审方法：把四个奖项的评选口径收敛成可打分的五维

四个奖各有侧重，但反复出现的共同口径只有五条，因此本项目直接按这五维自评、并逐条给证据：

| 奖项 | 官方口径里的关键词 | 收敛到本项目的评审项 |
|---|---|---|
| CA 国际设计奖 | 概念（concept）、工艺（craft）、视觉传达 | **美学与工艺**：线条、排版、比例是否经得起放大看 |
| 德国设计奖 | 整体概念、功能、美学、创新、可持续、社会责任 | **创新性** + **可持续性** + **功能性** |
| IDEA | 创新、用户价值、美学、细节、设计策略 | **用户体验** + **美学与工艺** |
| 红点奖 | 形式质量、功能、情感内容、耐久 | **美学与工艺** + **用户体验** + **可持续性** |

评分 5 分制，4.0 = "可以送审的水平"，4.5+ = "有机会入围"。**这是自评，不是获奖承诺**。

## 2. 整改前的现状盘点（全部有据）

用脚本把全站视觉常量扫了一遍（色板 / 线宽 / 圆角 / 字号 / 间距 / 透明度 / 动效），结论如下。

| 维度 | 整改前 | 关键证据 |
|---|---|---|
| 创新性 | **4.5** | 「手写纸 · 简约油墨」是完整自洽的概念：抖动由 `wobble(seed)` 纯函数生成（同一根线每次重绘完全一致，**不会闪**——这是"手绘感"落地最难的一环，见 `Ink.kt:88`）；**全站无彩色**，编辑状态靠线重 + 墨的浓淡表达（冲突格用排线而非标红） |
| 功能性 | **4.5** | 唯一解校验、笔记、候选、提示、撤销重做、存档 v1→v2 兼容、键盘全链路、悬浮输入面板（只列该格可填） |
| 美学与工艺 | **3.0** | 字号散落 **13 档**（10/11/12/13/14/15/16/17/18/21/22/28/40）且**无令牌、无行高、几乎无字重**；`lineHeight` 全站 0 处；"纸"有 **3 个来源**（`Ink.Paper` / `Ink.PaperShade` / `Color.White`）；存在**死令牌** `Ink.StrokeWidth`（4 个值与 `DesignTokens.Stroke` 全部冲突且零引用）；魔法尺寸 3 / 7 / 18 / 46 dp；分隔线硬编码 `1.2.dp`（重复了 `Stroke.Thin` 的值，改令牌不会同步） |
| 用户体验 | **3.5** | 键盘优先 ✓、悬浮键只列可填 ✓；但**"当前项"高亮几乎不可见**（底纹 `Wash×0.55 ≈ 0.039`，比悬停还淡）——键盘用户在抽屉里看不出焦点在哪一项；最淡一级墨 `#8B867C` 对纸面只有 **3.32:1**（小字不达 WCAG AA 4.5:1） |
| 可持续性 | **3.5** | 自绘控件不随第三方 UI 套件改版而失效 ✓；图标 / 资产一键再生 ✓；但设计令牌没有文档化的"唯一出口"约定，靠人记 ✗ |

## 3. 本轮已完成的整改（P0：工艺与可读性）

| # | 问题 | 改动 | 证据 |
|---|---|---|---|
| 1 | 字号 13 档、无阶梯、无行高 | 新增 `Ink.Type` **六档阶梯**（含字号 / 字距 / 行高三要素）：`Meta 12/1.6/18` · `Caption 14/0.8/22` · `Body 16/0.6/24` · `Title 20/2.0/30` · `Headline 28/4.0/40` · `Display 40/6.0/56`；29 处调用点全部改为引用角色 | 编译通过；截图 `sz_1180x900_1_menu` / `_4_game` |
| 2 | "纸"有三个来源 | 明确为**纸三层**并文档化：`Paper`（页面底纸）→ `PaperShade`（压印底纹）→ `PaperSheet`（上层纸片：棋盘 / 抽屉 / 浮层 / 暂停遮挡）；4 处 `Color.White` 全部替换 | `Ink.kt` 注释即规范 |
| 3 | 死令牌与数值冲突 | 删除 `Ink.StrokeWidth`（零引用、4 值与 `DesignTokens.Stroke` 冲突），并注明线宽只此一处 | 全项目仅 `DesignTokens.Stroke` 提供线宽 |
| 4 | 魔法尺寸 | `3/7` → `Spacing.Xs/Sm`；`18/46` → `Spacing.Md/Xxl`；`1.2.dp` → `Stroke.Thin`；`1.1f` → `Stroke.Hatch`；`4.dp.toPx()` → `Radius.Mark`；`24.dp` → `Sizes.MarkBox`；`52.dp` → `Sizes.KeyHeight`；`160.dp` → `Sizes.BoardMinSize / OverlayButtonWidth`；`12.dp` → `Sizes.DrawerGripOffset` | 扫描脚本复核：间距 / 线宽 / 圆角 / 字号的裸值归零 |
| 5 | 动效散值（240 / 180 / 90） | 新增 `DesignTokens.Motion`：`PressMs 90`（即时反馈）· `EnterMs 240`（进入）· `ExitMs 180`（**退场比进场快**）；3 处动画全部引用 | `TopDrawer.kt:188`、`InkWidgets.kt:112/117` |
| 6 | 透明度裸值 | 新增 `Alpha.Sheet 0.94`（浮层纸面）· `Alpha.Decor / DecorStep`（装饰墨点）· `Alpha.Hint 0.50`（候选数字）；`0.42f` → `Alpha.LineSoft` | 扫描脚本复核 |
| 7 | **"当前项"看不出** | `highlighted` 由 `Wash×0.55`（0.039）提到 `Wash`（0.07）**并加粗描边**（与 `emphasis` 同线宽）；抽屉里"当前项"与悬停同浓度 | 截图 `sz_1180x900_3_drawer_highlight`：1× 下即可辨出「普通」行为当前项（整改前需 2× 放大才看得出底纹） |
| 8 | 最淡墨不达 AA | 墨色改为**四级**：`Black 15.97:1` · `Grey 8.35:1` · `Light #6A655C 5.31:1`（可当正文用）· `Faint #8B867C 3.32:1`（**仅用于禁用态**，WCAG 对禁用控件不要求对比度） | 量算脚本输出（`docs/07` §5） |

**自评变化**：美学与工艺 3.0 → **4.0**，用户体验 3.5 → **4.5**，可持续性 3.5 → 4.0（令牌成为唯一出口且写进红线）。

## 4. 优化路线（P1 / P2，含验收标准）

### P1 — 直接影响评审结果

> 进度：#1 格子级语义、#2 减少动态效果 已于第七轮完成（`docs/05` §5.6）；#3 打包手写体已于第八轮完成（§5.7，正文霞鹜文楷 + 数字 Nunito，OFL）；#4 落笔成局待做。

| # | 项 | 为什么会影响评奖 | 验收标准 |
|---|---|---|---|
| 1 | **格子级无障碍语义** | IDEA 的 "Benefit to user"、德国设计奖的 "社会责任" 都是硬指标。当前棋盘是**整盘一个语义节点**，屏幕阅读器无法按格朗读"第 4 行第 7 列 = 空 / 候选 2、9" | Compose UI 测试断言语义树存在 81 个格子节点，且给定格与空格朗读文案不同（`docs/02` §7 待补项转正） |
| 2 | **尊重"减少动态效果"** | 系统级 reduced-motion 是当代无障碍与"社会责任"的常见扣分点；本项目动画虽少（3 处）但未响应系统开关 | 打开系统 reduced-motion 后，抽屉改为瞬时出现（时长 0），其余不变；用 UI 测试断言动画时长被替换 |
| 3 | **打包手写体** | 当前依赖系统楷书，取不到就回退衬线体 → **跨平台字形不一致**，这是"工艺一致性"的硬伤（评审会看同一设计在不同环境的呈现） | 打包一份开源可商用中文手写体（如霞鹜文楷 / 站酷系列），三平台字形完全一致；字体文件随 jar 分发，`docs/03` 记录许可与体积 |
| 4 | **落笔成局（棋盘初次呈现）** | 红点看"情感内容"：本作目前只有静态棋盘，缺一处**让人记住的瞬间**。建议：开局时棋盘以 120–160ms 的"墨迹由淡到浓"整体显影，且不阻塞计时 | 动效 ≤ 200ms、可被 reduced-motion 关闭；不影响首帧可交互（按键立刻可用）；冒烟截图留档 |

### P2 — 加分项，视排期安排

| # | 项 | 说明 |
|---|---|---|
| 5 | 纸色主题 | 暖白（当前）/ 冷白 / 灰纸三选一；**约束**：任一套都必须复核对比度 ≥ 4.5:1，且不引入色相 |
| 6 | 设计规格表（design sheet） | 把令牌导成一张可对外展示的规格图（色板、排版阶梯、线宽、圆角、间距、图标），供评审 / 外部设计师直接使用——"可持续性"里的可交接性 |
| 7 | 图标与界面再对齐 | 图标（九宫格 + 数字）已同源；可把图标的纸边内缩、圆角、线宽与 `DesignTokens` 再做一次逐项对齐，做到"同一套几何" |
| 8 | 规格化候选提示 | 若后续把候选数字当作**主信息**（而非冗余通道），需把 `Alpha.Hint` 提到 AA 并重新分配给定数字 / 候选的层级 |

### 已知取舍（不打算改，写清理由）

- **候选数字不做 AA 对比度**：它是有意为之的次级冗余通道——同一信息在悬浮面板（只列可填）与数字键盘的重墨强调里都能拿到，做得太黑会与"题目给定"的数字抢层级。浓度从 0.42 提到 0.50 已是可读性与层级感的平衡点；
- **不用字重做层级**：系统手写体没有真 Bold，Compose 合成粗体会发虚，破坏手绘工艺感。层级只靠"字号 + 字距 + 墨的浓淡"；
- **不做阴影 / 渐变 / 彩色状态**：与"只有纸与墨"直接冲突。

## 6. 结论

- **概念与工艺**已经是可送审水准（创新性 4.5 / 功能性 4.5）：手绘墨线的确定性抖动、无彩色的状态表达、"纸与墨"三层纸+四级墨的体系，都是能被评审记住的点；
- **短板集中在"系统化"而非"审美"**：字号无阶梯、"纸"多来源、死令牌、魔法尺寸、高亮不可辨、最淡墨不达 AA——本轮已全部整改并留证；
- 若要真去冲奖，**P1 的四项是门槛项**：格子级无障碍、reduced-motion、打包字体（跨平台字形一致）、一处可被记住的动效瞬间。前两项不做，功能与无障碍维度的失分会直接盖过美学加分。
