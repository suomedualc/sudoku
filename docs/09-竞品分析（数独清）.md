## 2. 玩法与结构（截图实证）

- **关卡体系**：`关卡模式-{星数}-{关号}`——**5 个星级（1~5 星）× 每星 150 关 = 750 关**；
  星数即难度梯度（给定量随星数递减：1 星 ~48 给定 → 5 星 ~12）；另设**随机模式**（完成任意 50 关解锁）。
- **关卡选择器即盘面预览**：← → 翻关 + 星级评价（每关 1~3 星）+ 竖排「开始」按钮。
- **双键盘并排**（核心输入设计）：左块 = 普通填数键盘（1–9 大字）；右块 = **笔记键盘**（1–9 各带 ° 角标）。
  两块**同时在场**——填数与记笔记零模式切换，杜绝"忘了切模式"的整个错误类别。
- **对局工具条**：撤销 / 重做 / 提示 / 设置 / 删除 五键悬浮于键盘下，带"挂点"装饰（视觉上像挂轴）。
- **设置面板**：音效、关于、重开本局、**统计图表 📊**、**主题换装 👕**、新的游戏。
- **视觉**：云海实景照片做沉浸背景 + 深色盘面（给定为深色圆角 tile）+ 白色圆角面板；主菜单以真实盘面做背景。

## 3. 可借鉴要素（按收益/成本排序）

| # | 要素 | 为什么值得借鉴 | 落地建议（贴合本项目） |
|---|---|---|---|
| 1 | **双键盘（填数 + 笔记）并排** | 消除"模式开关"这一整类状态错误；触屏上免切换的收益极大。我们当前笔记是全局开关（N 键/开关行），触屏用户切换有摩擦 | 悬浮面板与九宫格键盘增加"笔记分区"或长按=笔记；成本低，触屏收益高。桌面键盘不受影响（N 键已是零成本） |
| 2 | **进度体系（关卡/星级/解锁）** | 纯随机出题缺乏"旅程感"；竞品用 5 星 × 150 关 + 星级评分 + 解锁条件做长期目标 | 与现有 `GameStats` 融合：用已完成局数/胜场做**成就式门槛**（如"完成 50 局解锁大师+深挖洞"），不引入固定关卡库（保持无限出题优势）——对应 docs/05 Tier 2"技巧难度"方向 |
| 3 | **主题换装** | 竞品的 👕 换装面板验证了"皮肤系统"是数独 App 的标配预期 | 我们已有纸墨/夜墨双主题骨架（`Ink` getter 切换即换肤），docs/07 P2 的"纸色三选一"可低成本升级为换装面板 |
| 4 | **统计图表化** | 竞品统计用图表（📊 图标入口）；纯数字表不如图形直观 | `StatsSheet` 增加按难度的**墨线迷你柱状图**（完成局数分布），保持无彩色纪律 |
| 5 | **技巧引导文案** | "静止的数字玩累了？试试会动的策略！"——运营横幅引导探索功能 | 我们的句子位可低频混入**玩法技巧轮播**（候选提示怎么开、键位可自定义、Shift+方向跳空格），把"发现不了功能"的摩擦降到零 |
| 6 | **盘面即首页背景** | 主菜单直接展示一盘棋，沉浸且契合题材（比装饰草图更有叙事） | 低优先级：首页 `InkGridSketch` 可换为"上一局残局"的真实盘面剪影（淡墨） |

## 4. 我们的差异化（不借鉴清单 + 对比卖点）

- **不借鉴**：实景照片背景（与"只有纸与墨"美学直接冲突）；Unity 技术栈与渠道 SDK；强登录/实名/防沉迷链条。
- **对比卖点**（竞品的合规堆栈 = 我们的纯净标签）：**零权限**（竞品申请 READ_PHONE_STATE / QUERY_ALL_PACKAGES）、**零登录零实名**、**纯离线**、**21MB vs 49MB**、**MIT 开源**、OFL 字体内嵌。
- **决策提示**：若将来在国内应用商店上架，竞品的合规链（实名/防沉迷/版号相关）是国内网游发行的必要条件——届时需要专门的合规评估，而不是功能移植能解决的。

## 5. 结论

「数独清」是典型的**国内渠道化 Unity 数独**：强运营、强合规、内容量驱动（750 关）。其真正值得移植的是三个"交互与结构"层的设计——**双键盘免切换输入**（触屏收益最大，建议优先）、**进度门槛体系**（配合既有统计做成就式解锁）、**主题/换装面板**（已有双主题骨架）——三者都不与"纸与墨"美学或"无限随机出题"内核冲突。反方向，它的登录/实名/权限堆栈恰好反衬本作"纯净单机"的定位价值。
