## 1. 迭代 A：Android 收口（准出门槛，全部 S/M 规模）

> **进度（2026-10-08）**：A1 返回键导航、A4 测试脚本入库已完成——`ui/platform/SystemBackHandler` 三端桥 +
> GameScreen 拦截策略；`tools/android-smoke.ps1`（NoProfile + adb 密钥固定化）入库，用例扩至 T14（含设置抽屉
> 开关、九宫格填数、返回键三段语义）。剩余 A2（图标）、A3（AAB）、A5（真机）。

| 项 | 设计 | 技术路径 | UX 目标 |
|---|---|---|---|
| A1 返回键导航（D2） | 对局页返回 → 首页；抽屉打开 → 关抽屉；菜单页 → 系统默认 | `App` 增加可选 `interceptBack` 桥（commonMain 声明回调 + androidMain `BackHandler`），读取 `state.screen` 决定派发 `Navigate(Menu)` | 硬件返回不再"直接丢到桌面"，符合平台导航心智 |
| A2 自适应图标接线（D3） | `docs/06` 资源复制进 `androidMain/res/mipmap` + anydpi-v26 XML | 前景/背景分层已生成，仅复制 + 清单引用 | 启动器不再显示默认图标 |
| A3 AAB 打包 | `bundleRelease` + 签名配置（密钥决策走升级流程） | Gradle signingConfig；产物核对图标 / 版本名 | 具备商店交付形态 |
| A4 测试脚本入库 | `android_test.ps1`（14 用例 + 截图取证）正式化为 `tools/android-smoke.ps1`，字符串数据文件随行 | 从 Temp 迁入 + 用例补「设置抽屉开关」「九宫格填数」 | 窄屏/横屏回归可一键复跑 |
| A5 真机冒烟 | 至少 1 台实体设备过 §4 清单（触感 / 性能 / 推送类权限为零验证） | 手动 + 截图归档 | 软渲染之外的真实性能基线 |

## 2. 迭代 B：触屏输入体验（竞品借鉴 #1，规模 M）

- **双键盘免切换**：`NumberPad(grid)` 九宫格下方增加**笔记键盘块**（同竞品右块的 ° 角标语义，墨线化为"空心数字"）；触屏填数/笔记零切换。桌面 N 键路径不变。
- **横屏适配**（内部测试缺口）：手机横屏（宽 > 高）时功能区改**棋盘左 + 键盘右**双栏（复用宽屏断点思路，新断点"高 < 480dp 且宽 > 高"）。
- UX 目标：触屏完成"选格 → 填数 / 记笔记"全程单手、步数 ≤ 2；横竖屏切换不丢状态、无挤压。

## 3. 迭代 C：成长与可发现性（竞品借鉴 #2/#5，规模 M/L）

| 项 | 设计 | 技术路径 | UX 目标 |
|---|---|---|---|
| C1 成就式进度门槛 | 用 `GameStats` 既有数据派生解锁（完成 N 局 → 大师档"深挖洞"重试上限提升；统计里程碑解锁新墨线装饰） | `GameStats` 增派生属性 + reducer 锁定难度项 + 首页展示进度；**不引入固定关卡库**（保持无限出题内核） | 长期目标感；"随机出题"与"进度旅程"兼得 |
| C2 统计图表化 | `StatsSheet` 加按难度完成局数的**墨线迷你柱状图**（无彩色，纯墨阶） | 纯 Canvas 绘制，复用 inkLine/墨阶 | 统计一眼可读 |
| C3 技巧轮播 | `SentenceBook` 增"技巧"类目（候选提示怎么开 / 键位可自定义 / Shift 跳空格），句子位 20% 概率插入 | 数据文件加行 + 类别过滤 | 功能可发现性：让"不知道有这功能"归零 |

## 4. 迭代 D：个性化与发布决策（竞品借鉴 #3/#6，规模 S/M）

- **纸色换装面板**：docs/07 P2-5（暖白/冷白/灰纸）升级为换装抽屉（复用 TopDrawer + `Ink` 令牌 getter 扩展）；约束不变（每套 ≥ AA 对比度）。
- **首页残局剪影**：上一局盘面以淡墨做首页背景（替代装饰草图的升级项，情感化）。
- **国内渠道发布评估**（决策点，非开发项）：竞品合规链（实名/防沉迷/版号）是上架必要条件——需要专门的法务/渠道评估，不是功能移植；若不走国内渠道，"纯净离线"即核心卖点。
