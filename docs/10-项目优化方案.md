  三台 AVD 串行各一轮 **14/14 全 PASS**；逐条判定增量写 csv 存档 + 聚合重建实时 HTML 报告（浏览器 3s 自刷新、`-ReportOnly` 离线重建）；
  模拟器启动隐藏控制台窗口、有界退出等待、宽屏 T11 自动 SKIP。
- `docs/08` §8：三台设备结果矩阵（含 D1 九宫格、D2 返回键语义实证）。

**关键数据**：冷启动 2.6–3.2s（软渲染 AVD）· 内存 ~96–98 MB · 桌面回归 jvmTest 138/138 · 单轮全程 ~4–12 分钟（报表实时可见）。

**经验沉淀**（转入工程约定，后续所有模拟器轮次受益）：
1. **uiautomator 断言三层坑**：① XML 属性带引号，单段正则跨不过 → 两段式（先抓节点再提 bounds）；
   ② Compose 动画未停时 dump 陈旧 → 关键断言双 dump；③ 文本歧义（数字键角标与键面同文本，如 key 2 剩余数恰为 5）→ 按节点面积取键面（`-Largest`）。
2. **模拟器实例生命周期**：杀进程 ≠ 退净，旧实例未退净启动新实例必撞 AVD 锁 → 杀后有界等待（30s）+ 锁清理重试；**严禁两轮重叠**。
3. **PS 5.1 脚本工程**：脚本 ASCII-only、中文进 UTF-8 数据文件（ANSI 陷阱）；heredoc 不可用（用 `@'…'@`）；整条命令先整体解析（解析失败连前置命令都不跑）；跑脚本带 `-NoProfile`。
4. **数据与视图分离**：csv 是唯一事实源（增量落盘、跑中可读），report.html 是派生视图——存储层不动，展示层随时可换。
5. **AVD 名不符实**：Pixel_Tablet 实测 411dp（手机形态）——设备矩阵先 `wm size` 实测再下结论；宽屏路径由 jvmTest 覆盖。
6. **环境迁移验证法**：`.android`/`.gradle`/`.vcpkg` 迁 D 盘（junction + 用户级 env）后，用"构建→AVD 识别→模拟器→安装→用例"全链路冒烟验证，冷启动回落 2.6–3.2s 即无性能回归。

**推进排序**（迭代 A 准出三步，全部 S 规模）：
1. **A2 自适应图标**（D3）：`docs/06` 资源复制进 `androidMain/res/mipmap` + anydpi-v26 XML + 清单引用；
2. **A3 AAB 打包**：`bundleRelease` + signingConfig（密钥决策单独走升级流程），产物核对图标/版本名；
3. **A5 真机冒烟**：≥1 台实体设备过触感/性能清单（真实性能基线，替代软渲染保守数据）；
   → 准出后进入**迭代 B**（双键盘笔记块 + 横屏双栏适配，规模 M）。

## 2. 迭代 B：触屏输入体验（竞品借鉴 #1，规模 M）

- **双键盘免切换**：`NumberPad(grid)` 九宫格下方增加**笔记键盘块**（同竞品右块的 ° 角标语义，墨线化为"空心数字"）；触屏填数/笔记零切换。桌面 N 键路径不变。
- **横屏适配**（内部测试缺口）：手机横屏（宽 > 高）时功能区改**棋盘左 + 键盘右**双栏（复用宽屏断点思路，新断点"高 < 480dp 且宽 > 高"）。
- UX 目标：触屏完成"选格 → 填数 / 记笔记"全程单手、步数 ≤ 2；横竖屏切换不丢状态、无挤压。

## 4. 迭代 D：个性化与发布决策（竞品借鉴 #3/#6，规模 S/M）

- **纸色换装面板**：docs/07 P2-5（暖白/冷白/灰纸）升级为换装抽屉（复用 TopDrawer + `Ink` 令牌 getter 扩展）；约束不变（每套 ≥ AA 对比度）。
